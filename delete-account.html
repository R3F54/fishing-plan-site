Delete Account

This page explains the public account deletion path for Fishing Plan. It is intended for app review teams and users who want a clear support route.

Last updated: May 20, 2026

In-app deletion path

  1. Open Fishing Plan.
  2. Open the side menu from the main app experience.
  3. Select Delete Account.
  4. Confirm the deletion request inside the app.

What the deletion covers

The app is designed so that account deletion removes the user account connection and user-specific stored data associated with that account, including planning data, saved spots, catch logs and tackle-related profile information managed by the app's backend systems.

Guest mode

If a user is operating in guest mode, deletion may only clear local data stored on that device because no full signed account identity may be attached.

Alternative support request

If a user cannot access the app, they can request deletion support by emailing support@fishingplan.app from the email address associated with the account.

Support Contact

For account deletion help, contact support@fishingplan.app.
